# RuManual

Мобильный каталог автомобилей и ремонтных мануалов. Интерфейс рассчитан на Safari/iPhone и установку на экран «Домой».

## Что уже есть
- Каталог 6 марок: Kia, Volkswagen, Hyundai, Honda, Toyota, BMW.
- 14 карточек поколений/семейств моделей: Rio, Polo Sedan, Solaris, Civic, Camry, BMW 3 Series.
- Варианты двигателей, трансмиссий, кузовов, рынков и комплектаций с пометками о необходимости проверки по VIN.
- Карточка автомобиля с разделами «Обзор», «Мануалы», «Техданные».
- Подробные редакционные пошаговые карты для замены моторного масла и фильтра, передних тормозных колодок и воздушного фильтра.
- Технические значения показываются отдельно от неподтверждённых данных. Для Kia Rio FB добавлены отдельные значения из руководства Kia с указанием страниц и ссылок на источник.
- Адаптивный интерфейс и PWA-кэширование оболочки.

## Принцип достоверности
Наличие модели в каталоге не означает, что вся документация по ней уже собрана. Каждое значение должно быть привязано к рынку, году, коду двигателя, коробке и редакции источника. Неизвестные моменты затяжки, зазоры и объёмы помечаются как неподтверждённые, а не заменяются догадками.

Пошаговые карты, доступные сейчас, являются редакционными маршрутами работ. До маркировки как заводской процедуры они должны быть сверены с сервисной документацией конкретной модификации. Они не подменяют OEM-инструкцию.

## Публикация
GitHub Pages, ветка `main`, каталог `/`. После каждого обновления Service Worker меняет версию кэша.

## Ограничения текущего этапа
- Пока нет серверной БД, авторизации, редакторской панели и синхронизации между устройствами.
- VIN-декодер и внешний API не входят в текущую версию каталога.
- Полные схемы электропроводки, каталог деталей, все 23 поля заводских ремонтных карт и глобальная полнота ещё не реализованы.
- Для большинства поколений технические нормативы пока требуют заводских источников и проверки применимости.
