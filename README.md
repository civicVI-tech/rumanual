# RuManual

Мобильная веб-база знаний для автомеханика. Проект рассчитан на открытие в Safari на iPhone и установку на экран «Домой».

## Текущий состав
- Мобильный интерфейс на русском языке.
- Каталог автомобильных систем и учебных тем.
- Чек-листы и локальное сохранение прогресса.
- Локальный гараж с экспортом данных в JSON.
- Стартовый справочник нескольких DTC-кодов.
- VIN-декодирование через публичный NHTSA vPIC API (покрытие не универсальное).
- PWA manifest и service worker для кэширования оболочки.

## Публикация
Сайт публикуется через GitHub Pages из ветки `main`, каталог `/`.

## Важно о достоверности
Текущая версия — рабочая мобильная основа и стартовая база, а не полный заводской ремонтный справочник. Числовые технические нормы, моменты затяжки, зазоры, пределы износа и объёмы жидкостей нельзя добавлять без источника и точной применимости к автомобилю/двигателю/коробке. Примерные диагностические подсказки не заменяют OEM-процедуры.

## Данные пользователя
Прогресс и гараж хранятся в `localStorage` текущего браузера. Очистка данных Safari может удалить их; используйте экспорт данных в настройках.

## Ограничения
VIN-запрос требует интернета. В офлайн-режиме доступна только ранее закэшированная оболочка сайта. Общая синхронизация между устройствами и серверная база пока не реализованы.
